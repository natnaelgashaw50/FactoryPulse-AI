# FactoryPulse AI

## AI-Powered Smart Factory Management Platform

FactoryPulse AI is a modern industrial monitoring platform that combines IoT, Artificial Intelligence, Digital Twin technology, and Predictive Maintenance into one intelligent dashboard.

## Features

- Live IoT Dashboard
- AI Predictive Maintenance
- Failure Prediction
- Machine Health Monitoring
- Digital Twin Visualization
- Maintenance Scheduler
- Inventory Management
- Smart Alerts
- AI Chat Assistant
- JWT Authentication
- Role-Based Access Control
- PDF & Excel Reports

## Technology Stack

### Frontend
- React
- TypeScript
- Vite
- Tailwind CSS
- Three.js
- Recharts

### Backend
- Flask
- Flask SQLAlchemy
- Flask JWT Extended
- Flask SocketIO

### AI
- Scikit-learn
- RandomForest
- IsolationForest
- Pandas
- NumPy

### Database
- PostgreSQL
- SQLite (Development)

## Installation

### Backend

```bash
cd backend
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
python seed.py
python app.py
```

### Frontend

```bash
cd frontend
npm install
npm run dev
```
